# HTB-CTFs

A collection of Docker-based, Hack The Box-style security challenges built for hands-on learning.

Each challenge is designed to teach a specific attack path or security concept through practical enumeration, exploitation, privilege escalation, and post-exploitation thinking. The goal is to make the labs realistic enough to feel like a CTF box, but approachable enough for learners to understand the techniques behind each step.

## What To Expect

- Self-contained challenge environments
- HTB-style attack chains
- Web, Linux, API, cloud, and application-security themes
- Intentional rabbit holes and realistic misdirection
- Walkthroughs and maintainer notes where appropriate
- Resettable Docker deployments for repeated practice
